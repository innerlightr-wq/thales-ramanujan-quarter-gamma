# Results

Generated by `python scripts/run_all.py`. Do not edit by hand: the runner
overwrites all three files, and the outputs are deterministic, so any manual
change will show up as a spurious diff on the next run.

## `exact_identity_summary.csv`

One row per verified identity.

| Column | Meaning |
|---|---|
| `check_id` | stable identifier, e.g. `R3.2` |
| `group` | verification group, matching the `scripts/verify_*.py` that runs it |
| `description` | what is being verified |
| `exact_form` | the closed form asserted |
| `symbolic_status` | `verified`, `not applicable`, or a note explaining what was done instead (see `docs/computational_methods.md`) |
| `status` | `PASS` / `FAIL` |

## `high_precision_checks.csv`

One row per identity that carries an independent numerical audit.

| Column | Meaning |
|---|---|
| `numeric_dps` | working decimal digits used |
| `tolerance` | declared absolute-error bound; `0` means exact rational or integer arithmetic |
| `abs_error` | reported absolute error, three significant digits, `0e+0` for exact zero |
| `status` | `PASS` / `FAIL` |

## `clausen_parameter_audit.csv`

Hypergeometric parameters of each tested generating function against the
Clausen condition `c = a + b + 1/2`.

| Column | Meaning |
|---|---|
| `hypergeometric_form` | the function in hypergeometric notation |
| `a`, `b`, `c` | parameters (blank where the type has none) |
| `clausen_condition_applies` | `no` for the `1F0` cases, which have no second numerator parameter |
| `required_c` | the value of `c` the condition would demand |
| `clausen_condition_holds` | `yes` / `no` |

The table includes the Ramanujan square root `2F1(1/8, 3/8; 1; 256z)` as a
positive control, so that the obstruction is visibly specific rather than
vacuous. Its scope is exactly the generating functions listed — see
`docs/scope_and_nonclaims.md`.
